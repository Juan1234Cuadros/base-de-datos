# Informe Técnico: Introducción a Docker

## 📘 Descripción General
Este informe técnico presenta un resumen de los conocimientos adquiridos tras visualizar los videos **"Aprende Docker ahora! en 1:30"** y **"De Noob a Pro en 1 hora – Docker"**, los cuales explican los fundamentos y el uso práctico de Docker, una herramienta esencial para la creación, despliegue y ejecución de aplicaciones en contenedores.

---

## 🎬 Video 1: Aprende Docker ahora! en 1:30

### 🧩 Conceptos aprendidos
- **Docker** es una plataforma que permite empaquetar aplicaciones y todas sus dependencias en **contenedores**.
- Un **contenedor** es una unidad ligera y portátil que asegura que la aplicación funcione igual en cualquier entorno.
- **Imagen Docker**: plantilla base con el sistema y configuraciones necesarias para ejecutar un contenedor.
- **Docker Hub**: repositorio donde se almacenan y comparten imágenes Docker.
- **Comandos básicos**:
  - `docker pull` → descargar una imagen.
  - `docker run` → ejecutar un contenedor.
  - `docker ps` → listar contenedores activos.
  - `docker stop` → detener contenedores en ejecución.

### 💭 Reflexión personal
Este video es una introducción rápida pero clara a Docker. Me permitió entender el propósito de los contenedores y cómo simplifican el despliegue de aplicaciones. Lo más valioso fue comprender la diferencia entre una imagen y un contenedor, y cómo Docker mejora la portabilidad del software.

## 🎬 Video 2: De Noob a Pro en 1 hora – Docker

### 🧩 Conceptos aprendidos
- Instalación de Docker en distintos sistemas operativos.
- Creación y ejecución de contenedores personalizados.
- Uso de **Dockerfile** para automatizar la construcción de imágenes.
- Manejo de volúmenes para persistencia de datos.
- Configuración de redes entre contenedores.
- Introducción a **Docker Compose** para orquestar múltiples servicios.
- Buenas prácticas al construir y mantener contenedores.

### 💭 Reflexión personal
Este segundo video profundiza en el uso profesional de Docker. Aprendí cómo construir mis propias imágenes desde cero y cómo gestionar contenedores en entornos más complejos. Docker Compose me pareció una herramienta muy útil para manejar proyectos con varios servicios, como bases de datos y servidores web. Considero que Docker es clave en el desarrollo moderno, ya que ahorra tiempo y evita conflictos entre entornos.
